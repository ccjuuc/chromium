1. 启动 HTTPS 服务

需要 Node.js 24，以及已初始化的证书、TLS 私钥和扩展目录。保持终端运行，按 Ctrl+C 停止服务；导入新包后重启服务。

2. 启动专用测试浏览器

--data-dir
服务读取源码目录下 out/xl_extension_store 的证书和扩展包。
--user-data-dir
使用独立的 browser-profile 测试配置，保留测试安装状态。
--proxy-bypass-list
商店域名直连本机，避免经过系统代理。
--disable-xenon-sidebar-auto-hide
保持侧栏可见，便于使用 EXT 入口。
chrome://xenon-extension-store/
启动后打开本测试页。

本地域名映射

以管理员权限编辑 Windows 的 %SystemRoot%\System32\drivers\etc\hosts，添加一行：

127.0.0.1 xl.extensions.test.com

服务监听 127.0.0.1:443。浏览器已内置商店 CA 公共证书，无需安装到系统证书库；使用 HTTPS 默认端口 443。

安装与卸载检查

分别使用上方 XL 和 Google 示例包完成以下操作。

  1. 打开扩展详情，未安装时应显示可点击的“添加至 Chrome”。
  2. 点击安装并接受浏览器确认，完成后按钮自动变为“卸载”。
  3. 点击卸载后先取消，按钮保持“卸载”；再次点击并确认，按钮自动恢复为“添加至 Chrome”。
  4. 再次安装，再从 扩展管理页移除。返回商店详情后，应直接显示“添加至 Chrome”，无需刷新。
