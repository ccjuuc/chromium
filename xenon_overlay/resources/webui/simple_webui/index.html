📚 API Reference

One-way message (fire and forget):

chrome.send('logMessage', ['Hello', 'info']);

Two-way with Promise (request/response):

const info = await sendWithPromise('getSystemInfo');
console.log(info.operatingSystem);

C++ handler registration:

web_ui->RegisterMessageCallback(
    "getSystemInfo",
    base::BindRepeating(&Handler::HandleGetSystemInfo,
                        base::Unretained(this)));
